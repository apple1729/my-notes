1. _**用 Redis 扛不住吗？为什么要用本地缓存**_

**用本地缓存的优点：**

- 分摊 Redis 压力，解决热 Key 问题
- **降低中间件依赖与风险**：所有请求强依赖 Redis 会导致可能存在的风险：Redis 一旦抖动、超时、宕机，业务直接雪崩；而二级缓存可以做一层隔离，本地缓存命中时完全不依赖 Redis，提升系统容错性
- 默认情况下Redis的连接数是10000，秒杀场景下大量请求可能会打满Redis的连接，用本地缓存也能避免Redis连接上限

2. _**Redis单实例压力过大，为什么不搭建Redis集群**_

考虑成本问题，部署Redis集群的成本远高于本地缓存，并且本地缓存的速度比Redis缓存更快，所以可以优先选择本地缓存方案
