水印的本质其实很简单：

水印就是在原始内容上额外添加一层标记，用来表明版权、来源、归属或使用限制。

比如你在 CodeCV 制作简历，网站可能会在导出的 PDF 上添加自己的 Logo 或品牌标识。

但从技术角度看，水印有不同的实现方式。

## 一、最常见的四种水印原理

### 1. PDF 图层叠加（最容易处理）

### 图层叠加示意

原始 PDF 内容

简历文字、表格、图片

水印层

半透明 Logo / 文字

最终 PDF 页面

两层叠加显示

原理：

PDF 内部保存了正文对象和水印对象，打开时按照绘制顺序显示。

例如：

```
绘制简历正文
    ↓
绘制水印图片
    ↓
显示最终页面
```

如果水印是独立对象，就可以通过 PDF 编辑库删除对应对象。

你刚才那份简历就属于这种情况。

### 2. 透明度混合（最常见的视觉水印）

它的原理是 Alpha 混合。

假设：

- 原始背景颜色是白色，数值为 255。
    
- 水印颜色是灰色，数值为 100。
    
- 水印透明度为 20%。
    

最终显示颜色：

\[ C=0.2\times100+0.8\times255=224 \]

所以你看到的是浅灰色的水印。

它不一定是 PDF 专属技术，图片、网页和视频都可以这样做。

### 3. 内容直接合并（扁平化）

例如，把简历正文和水印一起渲染成一张图片，再把图片放进 PDF。

```
简历文字 + 水印
       ↓
    合并渲染
       ↓
    一张图片
       ↓
    PDF 页面
```

这时候水印已经不再是独立对象。

想去除就需要图像修复（Inpainting），根据周围像素推测被水印遮挡的内容。

### 4. 数字水印（肉眼看不到）

这种更有意思。

有些水印根本不是你能看到的 Logo，而是隐藏在文件中：

- 图片像素的细微变化。
    
- 音频信号的频率变化。
    
- PDF 的元数据或内部标记。
    
- 特定编码结构中的信息。
    

例如数字图像水印可以通过修改某些像素或频域系数，嵌入版权信息。

即使看不到，也可能通过专门算法检测出来。

## 二、为什么有的水印能直接删除，有的不能？

关键在于：水印和原始内容有没有分离。

|类型|水印是否独立|处理方式|
|---|---|---|
|独立文字对象|是|删除文字对象|
|独立图片对象|是|删除图片对象|
|独立矢量绘图|是|删除对应绘图指令|
|扁平化图片|否|图像修复|
|隐藏数字水印|不一定|根据嵌入算法处理|

## 三、这里有一个很值得学习的计算机知识

你可以把 PDF 理解成一个小型的绘图程序。

它不一定存储最终页面的完整图片，而是可以存储一系列指令：

```
1. 在坐标 (100, 100) 绘制文字
2. 在坐标 (200, 200) 绘制矩形
3. 加载一张图片
4. 设置透明度为 0.2
5. 在页面中央绘制图片
```

打开 PDF 时，阅读器执行这些指令，最终把页面呈现出来。

所以 PDF 不只是文档格式，它也包含了页面描述和绘制机制。

这也是为什么你学习的 Python、PDF 对象结构、图像处理，能够组合起来实现 PDF 编辑工具。
