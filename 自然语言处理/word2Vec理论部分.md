使用梯度下降公式：
![[Pasted image 20261018232611.png]]

现在，我们只关注两个向量：

- 中心词 `love` 的输入向量。
- 正确目标词 `deep` 的输出向量。

为了方便计算，我们先研究 `deep` 的输出向量应该怎样调整。

## 1. 梯度告诉我们什么？

对于 Softmax 加交叉熵损失，有一个很重要的结果：

\[ \boxed{ \frac{\partial L}{\partial z_w} = P(w\mid c)-y_w } \]

其中：

- \(P(w\mid c)\) 是模型预测的概率。
- \(y_w\) 是正确标签：如果 \(w\) 是正确答案，则为 1；否则为 0。

对于正确答案 `deep`：

\[ \frac{\partial L}{\partial z_{\text{deep}}} = 0.265-1 \]

得到：

\[ \boxed{-0.735} \]

为什么是负数？

因为模型给正确答案分配的概率还不够高，所以优化过程需要调整参数，让正确答案的得分提高。

对于错误候选词，梯度则为其预测概率，因为对应的正确标签为 0。

例如，如果模型给 `I` 的概率是 0.247：

\[ \frac{\partial L}{\partial z_{\text{I}}}=0.247-0 \]

因此：

\[ \boxed{0.247} \]

这说明模型还需要调整参数，降低错误候选词相对于正确答案的竞争优势。

## 2. 梯度如何影响词向量？

回到点积公式：

\[ z_{\text{deep}}=u_{\text{deep}}^Tv_{\text{love}} \]

我们知道：

\[ u_{\text{deep}}= \begin{bmatrix} 0.2\\ 0.6 \end{bmatrix} ,\qquad v_{\text{love}}= \begin{bmatrix} 0.5\\ 0.3 \end{bmatrix} \]

因为：

\[ z_{\text{deep}} = u_1v_1+u_2v_2 \]

所以，对输出向量求偏导：

\[ \frac{\partial z_{\text{deep}}}{\partial u_{\text{deep}}} = v_{\text{love}} \]

结合链式法则：

\[ \boxed{ \frac{\partial L}{\partial u_{\text{deep}}} = \left(P(\text{deep}\mid\text{love})-1\right) v_{\text{love}} } \]

代入数字：

\[ \frac{\partial L}{\partial u_{\text{deep}}} = -0.735 \begin{bmatrix} 0.5\\ 0.3 \end{bmatrix} \]

得到：

\[ \boxed{ \frac{\partial L}{\partial u_{\text{deep}}} = \begin{bmatrix} -0.3675\\ -0.2205 \end{bmatrix} } \]

这就是 `deep` 输出向量对应的梯度。

它告诉我们：如果只考虑这个正确词对应的分数，沿负梯度方向调整输出向量，就能提高它与中心词向量的点积。

不过，完整的 Softmax 损失还包含其他候选词的影响。我们接下来会用完整的梯度更新公式。

---

# 六、第五步：使用梯度下降，真正更新词向量

假设学习率为：

\[ \alpha=0.1 \]

梯度下降公式：

\[ u_{\text{deep}}^{new} = u_{\text{deep}}^{old} - \alpha \frac{\partial L}{\partial u_{\text{deep}}} \]

代入：

\[ u_{\text{deep}}^{new} = \begin{bmatrix} 0.2\\ 0.6 \end{bmatrix} - 0.1 \begin{bmatrix} -0.3675\\ -0.2205 \end{bmatrix} \]

计算：

\[ u_{\text{deep}}^{new} = \begin{bmatrix} 0.2+0.03675\\ 0.6+0.02205 \end{bmatrix} \]

最终得到：

\[ \boxed{ u_{\text{deep}}^{new} = \begin{bmatrix} 0.23675\\ 0.62205 \end{bmatrix} } \]

看到了吗？

原来的向量是：

\[ [0.2,0.6] \]

更新之后变成：

\[ [0.23675,0.62205] \]

**这就是梯度下降更新词向量的过程：计算损失对词向量的梯度，然后沿负梯度方向调整向量中的每一个数值。**

这里的计算只考虑了正确词对应的分数对输出向量的影响。完整的 Softmax 更新还会考虑其他候选词的梯度。

---

# 七、第六步：为什么中心词的向量也会被更新？

你可能会问：

我们刚刚更新的是 `deep` 的输出向量，那么 `love` 的输入向量呢？

它也会更新。

因为：

\[ z_{\text{deep}}=u_{\text{deep}}^Tv_{\text{love}} \]

点积同时受到两个向量的影响。

对中心词向量求导，可以得到：

\[ \boxed{ \frac{\partial L}{\partial v_{\text{love}}} = \sum_{w\in V} \left(P(w\mid\text{love})-y_w\right)u_w } \]

这意味着，中心词的向量也会根据所有候选词的预测误差进行调整。

在一次训练更新中：

- `love` 的输入向量会更新。
- 各个候选词的输出向量也会根据梯度更新。

对于正确的目标词，模型倾向于提高它与中心词的匹配得分；对于其他候选词，模型则会调整它们的相对得分。

**因此，Word2Vec 不是只修改正确单词的向量，而是根据损失函数的梯度，更新所有参与计算的相关参数。**

# 九、最终，为什么词向量会具有语义？

你可能会觉得奇怪：

我们一直在做预测，为什么最终得到的向量就能反映词语的含义？

原因在于，**一个词经常与哪些词一起出现，本身就包含了关于这个词的统计信息。**

例如，在大量文本中：

- `cat` 经常与 `pet、animal、kitten` 等词共同出现。
- `dog` 也经常与 `pet、animal、puppy` 等词共同出现。

训练过程中，为了让模型更准确地预测这些上下文，`cat` 和 `dog` 的向量可能逐渐形成相似的分布式表示。

所以，训练结束后，语义相近的词往往具有更接近的向量。

但这不是绝对规律，具体结果取决于训练语料、模型设置和优化过程。

|步骤|做什么|对应的数学工具|
|---|---|---|
|1|随机初始化词向量|随机参数初始化|
|2|选择中心词和上下文词|Skip-gram 训练样本|
|3|计算中心词与候选词的匹配分数|向量点积|
|4|将分数转换为概率|Softmax|
|5|衡量预测与真实上下文的差距|交叉熵损失|
|6|计算损失对词向量的影响|反向传播、链式法则|
|7|沿负梯度方向调整词向量|梯度下降或 SGD|
|8|重复处理更多训练样本|迭代优化|
|9|得到训练后的词向量|学习到的向量表示|

**你真正需要掌握的核心是：**

Word2Vec 先用词向量预测上下文，通过 Softmax 得到预测概率，再用损失函数衡量预测效果。随后通过反向传播计算损失对词向量的梯度，并利用 SGD 更新词向量。不断重复这个过程，词向量就会逐渐学到语料中蕴含的语义和上下文规律。
